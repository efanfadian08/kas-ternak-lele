Panduan Integrasi Excel

1 Ekspor File Excel (.xlsx)

Klik tombol "Ekspor Excel" di pojok kanan atas. Sistem secara otomatis mendownload spreadsheet rapi berisi Rekap Saldo, detail Pemasukan, dan Pengeluaran.

2 Impor dari Excel

Klik "Impor Excel" untuk memasukkan data transaksi dari file Excel (.xlsx). Pastikan kolom file Excel memiliki nama: Tanggal, Jenis, Kategori, Keterangan, Jumlah.

3 Salin Tabel Quick Paste

Gunakan tombol "Salin Tabel" untuk meng-copy seluruh riwayat transaksi. Anda bisa langsung menempelkannya (`Ctrl + V`) ke Google Sheets atau Microsoft Excel secara instan.
